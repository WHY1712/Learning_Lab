```
x=int(input())
y=int(input())

quotient=x // y
remainder=x%y

print(quotient,remainder)

float_result = x/y
print(f"{float_result:.2f}")
```

- input()输入为字符型，如果用作数字，必须加类型转换 int()

- // ；整除结果；% ：除余结果；/ ：除法结果，存在小数
  
- f-string（格式化字符串字面量）：在字符串引号前添加 `f` 或 `F`，Python 会解析字符串中的 `{}` 内容，并将其中的变量或表达式结果替换到对应位置。

- `{}`：用于包裹需要插入字符串中的变量或表达式，Python 会先计算其中的内容，再将结果转换为字符串输出。例如：`f"{x+1}"`。

- `:`：用于指定格式化规则，位于表达式之后，用于分隔数据内容和格式说明符。例如：`f"{x:.2f}"`。

- `.2f`：格式说明符，其中 `.2` 表示保留小数点后两位，`f` 表示使用浮点数格式输出。对于浮点数会自动进行四舍五入。


# map语法
map(int, input().split())

用于一次输入多个数据，并将输入内容转换为指定类型。

执行过程：

1. `input()`：读取一行输入，返回字符串。
2. `split()`：按照空格切分字符串，得到多个字符串元素。
3. `map(int, ...)`：将每个字符串转换为整数。
4. 使用多个变量接收转换后的结果。

例如：

```python
a, b = map(int, input().split())
```

# 逻辑运算与位运算

## 1. 逻辑运算符

逻辑运算用于判断变量的真假关系。

| 运算符 | 名称 | 作用 |
| --- | --- | --- |
| `and` | 逻辑与 | 两个值都为真时返回真 |
| `or` | 逻辑或 | 两个值有一个为真时返回真 |
| `not` | 逻辑非 | 对真假结果取反 |

示例：

```python
print(1 and 3)   # 输出 3
print(0 or 3)    # 输出 3
print(not 0)     # 输出 True
```

注意：

- `0` 表示 `False`，非零数字表示 `True`。
- `and`、`or` 返回参与运算的值，不一定返回布尔值。


## 2. 位运算符

位运算直接对整数的二进制位进行操作。

| 运算符 | 名称 | 规则 |
| --- | --- | --- |
| `&` | 按位与 | 两个位都为 1，结果为 1 |
| `|` | 按位或 | 两个位有一个为 1，结果为 1 |
| `~` | 按位取反 | 二进制位 0 和 1 互换 |

例如：

```python
5 & 3
```

二进制：

```
  0101
& 0011
------
  0001
```

结果：

```
1
```

## 3. 逻辑运算与位运算区别

| 类型 | 运算符 | 用途 |
| --- | --- | --- |
| 逻辑运算 | `and`、`or`、`not` | 判断真假关系 |
| 位运算 | `&`、`\|`、`~` | 操作整数二进制位 |

注意：

```
and ≠ &
or  ≠ |
not ≠ ~
```

- 逻辑运算用于条件判断；
- 位运算用于二进制数据处理。
